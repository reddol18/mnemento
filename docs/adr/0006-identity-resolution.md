# ADR-0006: 동일 엔티티 판정 — 결정적 규칙 우선, LLM은 후보 제안만

- 상태: 채택 · 2026-10-02

## 맥락
같은 회사가 "가상테크", "(주)가상테크", "Gasang Tech"로 들어온다. 판정이 틀리면 "예전에 지원했나?"에 잘못 답한다. 반대로 LLM에게 자동 병합을 맡기면 서로 다른 회사를 합쳐 버리는 사고가 난다 — 실제로 목록상 "서초구"인 공고의 실근무지가 성남이었고, 이름만으로는 서치펌인지 알 수 없었다.

## 결정 (위에서부터 적용)
1. **외부 식별자** — 플랫폼+공고번호(`saramin:10000001`), 사업자등록번호가 같으면 동일. 가장 강한 근거.
2. **정규화 이름 + 별칭 사전** — `(주)`, `주식회사`, 공백, 대소문자, 괄호 속 영문명을 제거·통일한 키가 같거나 별칭 사전에 등록돼 있으면 동일.
3. **LLM 후보 제안** — 위 둘로 못 정하면 LLM이 "같을 가능성이 있는 후보"만 제시한다. **자동 병합하지 않고** 요청한 에이전트(또는 사용자)에게 되묻는다.
4. 병합은 `merged` 이벤트로 남기고 **되돌릴 수 있게**(`unmerged`) 한다. 확정된 병합은 별칭 사전에 자동 등록.

## 결과
- 오판의 비용(잘못된 병합)이 미판정의 비용(되묻기 한 번)보다 크다는 판단을 규칙에 반영했다.
