# ADR-0007: 정정과 삭제 — 정정은 이벤트로, 물리 삭제는 개인정보 요청에만

- 상태: 채택 · 2026-10-02

## 맥락
기록은 틀릴 수 있다(예: 지원한 곳을 패스로 잘못 기록). 이벤트를 지우면 "왜 숫자가 바뀌었나"를 설명할 수 없다. 반면 개인정보는 요청 시 실제로 지워야 한다.

## 결정
1. **정정** — 원래 이벤트를 수정하지 않고, 그것을 가리키는 `corrected` 이벤트를 추가한다(무엇을·왜·근거). 현재 상태는 정정을 반영해 다시 계산된다.
2. **철회** — 잘못 들어간 기록 전체는 `retracted` 이벤트로 무효 표시. 질의 결과에서는 빠지고, 이력 조회에서는 보인다.
3. **물리 삭제** — 개인정보 삭제 요청 같은 경우에만 별도 명령(`purge`)으로 실제 삭제한다. 삭제 사실(대상 id·시각·사유)만 남기고 내용은 남기지 않는다.
4. 모든 숫자 답변은 정정·철회가 반영된 상태 기준이며, 요청하면 정정 이력을 함께 보여 준다.
