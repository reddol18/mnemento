# ADR-0003: 사건 누적(events) + 현재 상태(entities)

- 상태: 채택 · 2026-10-02

## 맥락
"열람됨 → 탈락"처럼 상태가 바뀐다. 덮어쓰면 "언제 열람됐나", "누가 무슨 근거로 바꿨나"를 답할 수 없다.

## 결정
- 모든 변화는 `events`에 **추가만** 한다(누가·언제·무엇·근거).
- `entities`는 events를 반영한 **현재 상태**이며, 언제든 events에서 다시 만들 수 있다.
- 정정도 삭제가 아니라 **정정 event**로 남긴다.

## 결과
- 모든 숫자 답변에 근거(event 목록)를 붙일 수 있다.
- 저장 공간이 늘지만 개인 규모에선 무시 가능.
