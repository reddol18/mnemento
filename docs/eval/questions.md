# 평가 문항 (v0 구직 도메인)

실데이터 정답은 `data/private/eval_answers.json`(비공개)에 두고, 공개 저장소에는 **가상 데이터로 같은 형태의 문항과 정답**을 둔다.
각 문항은 ① 해석 ② 질의 정의 ③ 답변(근거·한계 포함)이 모두 맞아야 정답으로 친다.

| # | 질문 | 유형 | 검증 포인트 |
|---|---|---|---|
| Q1 | (특정 날짜) 사람인 지원 몇 곳? | 집계 | 정답 개수 + 근거 목록. "오늘" 해석이 시간대 기준인지(ADR-0004) |
| Q2 | (특정 회사) 예전에 지원한 적 있나? | 동일 엔티티 | 회사 정규화·별칭(ADR-0006)으로 정확한 건수 |
| Q3 | 열람됐는데 결과 없는 곳은? | 상태 필터 | status=viewed, 결과 이벤트 없음 |
| Q4 | 예상 합격률 상위 10%가 30%보다 먼저 열람되나? 지난번에도 그랬나? | 그룹 비교·기간 분할 | 월별·등급별 집계, **표본 수 경고와 미완료 데이터 경고**를 답에 포함 |
| Q5 | 열람까지 평균 몇 시간 걸렸나? 빠르게 열람된 곳의 결과는? | 파생 필드 | 열람 시각 − 지원 시각, 결과와 연결 |
| Q6 | 지원 개수를 정정한 적 있나? 왜? | 정정 이력 | corrected 이벤트와 근거(ADR-0007) |
| Q7 | 서치펌 공고로 확인돼 패스한 곳은? | 자유 서술 필드 | reason 텍스트 기반 — 구조화 필드 제안이 나오는지(5-1 B) |
