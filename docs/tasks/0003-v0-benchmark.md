# 작업 0003 — v0 3단계: 벤치마크 (정확도·속도·비용)

- 지시: 지휘부 · 2026-10-03 · 선행: 0002 완료·지휘부 검수 통과
- 근거: PLAN 2-1, ADR-0008

## 만들 것
1. **가상 데이터 생성기** — 구직 도메인, 규모 100 / 1,000 / 10,000건. 실데이터와 같은 분포 특성(상태 비율, 정정·철회, 별칭 회사)을 흉내 내되 실명·실공고 금지.
2. **평가 문항 공개판** — `docs/eval/questions.md` Q1~Q7을 가상 데이터 기준으로 정답 고정(채점 기준 사전 고정).
3. **비교군 러너** — B0 전체 컨텍스트 / B1 마크다운 메모리 + 파일 검색 / (가능 시) B2 벡터 메모리 / M Mnemento. 같은 모델·온도, 문항당 5회 이상.
4. **측정** — 정답률, 응답 시간 평균·p95, 입력·출력 토큰(캐시 별도), 금액(측정일 공식 단가 명시).
5. **결과 저장·리포트** — 원자료 JSON을 `bench/results/`에, README 표와 규모별 그래프를 결과에서 자동 생성.

## 완료 기준
- 재현 명령 한 줄로 전체 벤치마크 실행 가능
- README 벤치마크 표 채움(지는 항목 포함, 이유 기재)
- 지휘부 보고: 세 지표 요약, 가설("규모가 커질수록 M의 비용 우위") 검증 결과
